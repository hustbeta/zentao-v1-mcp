## 获取版本详情

### 请求URL

https://xxx.com/api.php/v1/builds/id

### 请求头

| 名称 | 类型 | 必填 | 描述 |
| --- | --- | --- | --- |
| Token | String | 是 | 认证凭证Token |

### 请求响应

| 名称 | 类型 | 必填 | 描述 |
| --- | --- | --- | --- |
| id | int | 是 | 版本ID |
| project | int | 是 | 所属项目 |
| product | int | 是 | 所属产品 |
| branch | int | 是 | 所属产品分支（主分支为0） |
| execution | int | 是 | 所属执行 |
| name | string | 是 | 版本名称 |
| scmPath | string | 是 | 源代码地址 |
| filePath | string | 是 | 下载地址 |
| desc | string | 是 | 版本描述 |
| builder |  | 是 | 构建者 |
| date | date | 是 | 打包日期 |
