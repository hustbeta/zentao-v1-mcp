## 获取项目的测试单

### 请求URL

https://xxx.com/api.php/v1/projects/id/testtasks

### 请求头

| 名称 | 类型 | 必填 | 描述 |
| --- | --- | --- | --- |
| Token | String | 是 | 认证凭证Token |

### 请求响应

| 名称 | 类型 | 必填 | 描述 |
| --- | --- | --- | --- |
| page | int | 是 | 当前页面 |
| total | int | 是 | Bug总数 |
| limit | int | 是 | 每页Bug数 |
| testtasks | array | 是 | 测试单列表 |
| ∟ id | int | 是 | 测试单编号 |
| ∟ project | int | 是 | 所属项目 |
| ∟ product | int | 是 | 所属产品 |
| ∟ name | string | 是 | 测试单名称 |
| ∟ execution | int | 是 | 所属执行 |
| ∟ build | int | 是 | 所属版本 |
| ∟ type | string | 否 | 类型 |
| ∟ owner |  | 否 | 负责人 |
| ∟ pri | int | 否 | 优先级 |
| ∟ begin | date | 否 | 开始日期 |
| ∟ end | date | 否 | 结束日期 |
| ∟ desc | string | 是 | 描述 |
| ∟ status | string | 是 | 状态(wait 未开始 \| doing 进行中 \| done 已关闭 \| blocked 被阻塞) |
| ∟ branch | int | 是 | 所属分支 |
