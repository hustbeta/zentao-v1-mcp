## 查看执行详情

### 请求URL

https://xxx.com/api.php/v1/executions/id

### 请求头

| 名称 | 类型 | 必填 | 描述 |
| --- | --- | --- | --- |
| Token | String | 是 | 认证凭证Token |

### 请求响应

| 名称 | 类型 | 必填 | 描述 |
| --- | --- | --- | --- |
| id | int | 是 | 执行ID |
| project | int | 是 | 所属项目 |
| name | string | 是 | 执行名称 |
| code | string | 是 | 执行代号 |
| begin | date | 是 | 计划开始日期 |
| end | date | 是 | 计划结束日期 |
| days | int | 否 | 可用工作日 |
| lifetime | string | 否 | 类型(short 短期 \| long 长期 \| ops 运维) |
| PO |  | 否 | 产品负责人 |
| PM |  | 否 | 迭代负责人 |
| QD |  | 否 | 测试负责人 |
| RD |  | 否 | 发布负责人 |
| teamMembers | array | 否 | 团队成员 ["admin"] |
| desc | string | 是 | 迭代描述 |
| acl | string | 是 | 访问控制(private 私有 \| open 继承项目权限) |
| whitelist | array | 否 | 白名单 |
| openedBy |  | 是 | 创建人 |
| openedDate | datetime | 是 | 创建时间 |
