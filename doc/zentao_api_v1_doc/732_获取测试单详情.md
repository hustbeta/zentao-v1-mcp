## 获取测试单详情

### 请求URL

https://xxx.com/api.php/v1/testtasks/id

### 请求头

| 名称 | 类型 | 必填 | 描述 |
| --- | --- | --- | --- |
| Token | String | 是 | 认证凭证Token |

### 请求响应

| 名称 | 类型 | 必填 | 描述 |
| --- | --- | --- | --- |
| id | int | 是 | 测试单编号 |
| project | int | 是 | 所属项目 |
| product | int | 是 | 所属产品 |
| name | string | 是 | 测试单名称 |
| execution | int | 是 | 所属执行 |
| build | int | 是 | 所属版本 |
| type | string | 否 | 类型(integrate 集成测试 \| system 系统测试 \| acceptance 验收测试 \| performance 性能测试 \| safety 安全测试) |
| owner |  | 否 | 负责人 |
| pri | int | 否 | 优先级 |
| begin | date | 否 | 开始日期 |
| end | date | 否 | 结束日期 |
| desc | string | 否 | 描述 |
