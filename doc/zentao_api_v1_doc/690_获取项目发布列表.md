## 获取项目发布列表

### 请求URL

https://xxx.com/api.php/v1/projects/id/releases

### 请求头

| 名称 | 类型 | 必填 | 描述 |
| --- | --- | --- | --- |
| Token | String | 是 | 认证凭证Token |

### 请求响应

| 名称 | 类型 | 必填 | 描述 |
| --- | --- | --- | --- |
| total | int | 是 | 发布总数 |
| releases | array | 是 | 发布列表 |
| ∟ id | int | 否 | 发布编号 |
| ∟ project | int | 否 | 所属项目 |
| ∟ product | int | 否 | 所属产品 |
| ∟ branch | int | 否 | 所属分支 |
| ∟ build | int | 否 | 所属版本 |
| ∟ name | string | 否 | 发布名称 |
| ∟ date | date | 否 | 发布日期 |
| ∟ desc | string | 否 | 描述 |
| ∟ status | string | 否 | 状态(normal 正常 \| terminate 停止维护) |
